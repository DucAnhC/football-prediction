# PROJECT_RULES.md

## Product Direction
This app is not just a scoreboard. It is a football analysis and prediction product.

## Core User Value
Users come for:
- fast score updates
- readable statistics
- useful pre-match analysis
- structured prediction support

## Important Domain Notes
- Focus on major leagues first
- Prioritize pre-match and in-match clarity
- Prediction must be explained in human-readable form
- Confidence must stay realistic

## Prediction Philosophy
- Predictions are probabilistic, not certain
- Statistical indicators must support the final lean
- Handbook knowledge is used as domain guidance
- Avoid sensational or absolute language

## UX Priority
1. clarity
2. speed
3. scanability
4. consistency
